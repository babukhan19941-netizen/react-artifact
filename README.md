## 🚀 How to Build APK on GitHub (Automated)

1. **Create a new Repository on GitHub** (e.g., `react-artifact`).
2. **Extract and Push these files to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of React Artifact Android project"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/react-artifact.git
   git push -u origin main
   ```
3. **Download your APK**:
   - Go to your repository on GitHub.
   - Click the **Actions** tab.
   - Click the latest workflow run: **Build Android APK**.
   - Under **Artifacts**, download `React-Artifact-debug-apk.zip` or release APK!
   - Unzip and install the `.apk` on your Android phone.

## 💻 How to Open in Android Studio

1. Open **Android Studio** (Koala / Ladybug / Meerkat or newer).
2. Choose **Open** and select this folder.
3. Gradle will automatically sync using Gradle **9.3.1**.
4. Click **Run ▶** to test on an emulator or connected phone.
5. Go to **Build > Build Bundle(s) / APK(s) > Build APK(s)** to generate local APK.
